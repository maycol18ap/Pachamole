# ML — reglas locales

- Python para datasets y modelos; no agregar paquetes JS a este subproyecto salvo razón aprobada.
- Etiquetar inequívocamente datos sintéticos; nunca presentarlos como ventas reales.
- Generador reproducible con semilla, supuestos y esquema documentados.
- Separación entrenamiento/prueba adecuada para datos temporales; evitar fuga de información.
- Comparar con baseline ingenuo, evaluar MAE/RMSE y explicar limitaciones.
- No bloquear backend ni checkout por la entrega de ML. Integración opcional y desacoplada.
- No subir datasets con datos personales reales ni archivos binarios grandes innecesarios.
